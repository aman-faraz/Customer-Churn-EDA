# Customer Churn EDA

An Exploratory Data Analysis (EDA) project on Customer Churn prediction using the Telco Customer Churn dataset.  
This project focuses on understanding customer behavior, identifying churn patterns, and extracting business insights through data visualization and analysis.

---

## Project Overview

Customer churn is one of the major challenges faced by telecom companies.  
This project performs detailed exploratory analysis to identify factors influencing customer churn and provides insights that can help improve customer retention strategies.

---

## Files in Repository

### 1. `customer_churn.csv`
Dataset used for analysis containing customer demographic information, account details, services subscribed, and churn status.

### 2. `telco_EDA.py`
Python script containing:
- Data loading
- Data cleaning
- Exploratory Data Analysis
- Visualization
- Statistical insights

### 3. `telco_EDA_report`
Project report/documentation containing:
- Analysis summary
- Findings
- Charts & observations
- Business insights

---

## Sample Insights

- Customers with month-to-month contracts show higher churn rates.
- Electronic check payment users tend to churn more frequently.
- Longer tenure customers are less likely to churn.
- Fiber optic internet users show comparatively higher churn.

## How to Run the Project

1. Clone the repository

```bash
git clone https://github.com/aman-faraz/Customer-Churn-EDA.git
```

2. Install required libraries

```bash
pip install pandas numpy matplotlib seaborn
```

3. Run the Python file

```bash
python telco_EDA.py
```
